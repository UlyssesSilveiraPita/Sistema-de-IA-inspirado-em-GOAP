# Sistema de IA inspirado em GOAP para RPG de Aventura

Sistema avançado de IA desenvolvido em Unity 6.2 utilizando C#, inspirado na arquitetura GOAP (Goal Oriented Action Planning) para jogos RPG de aventura em terceira pessoa inspirados em Zelda.

O projeto foi desenvolvido com foco em IA dinâmica, tomada de decisão contextual, combate inteligente e arquitetura modular escalável.

---

## Tecnologias Utilizadas

- Unity 6.2
- C#
- NavMesh
- Scriptable Objects
- Event System
- State Machine
- Blackboard System
- Utility AI
- GOAP-like Architecture
- Component Based Architecture
- SOLID Principles

# GOAP Inspired AI System for Adventure RPG

Advanced AI system developed in Unity 6.2 using C#, inspired by GOAP (Goal Oriented Action Planning) architecture for third-person adventure RPG games inspired by Zelda.

This project focuses on dynamic AI, contextual decision making, intelligent combat behavior and scalable modular architecture.

---

## Technologies Used

- Unity 6.2
- C#
- NavMesh
- Scriptable Objects
- Event System
- State Machine
- Blackboard System
- Utility AI
- GOAP-like Architecture
- Component Based Architecture
- SOLID Principles

---

## Main Features

### Dynamic AI System
Enemies analyze the environment in real time and make decisions based on:

- Combat pressure
- Environment geometry
- Distance to target
- Stamina amount
- Current combat state
- Dynamic priorities

---

### Implemented Behaviors

- Patrol system
- Cover seeking
- Melee combat
- Ranged combat
- Strategic retreat
- Target chasing
- Stamina management
- Dynamic behavior switching
- Contextual action selection

---

### AI Systems

- GOAP-inspired Planner
- Utility AI
- Finite State Machine (FSM)
- Blackboard System
- Sensor System
- Vision System
- NavMesh Pathfinding
- Priority System
- Event Driven Architecture

---

## Project Architecture

The project architecture was built using:

- Scriptable Objects
